# Project rules

- The application must never create, modify, rename or delete anything in the Run8 install directory `C:\Run8Studios\Run8 Train Simulator V3` or its subfolders. It may only read from there. It must refuse any data or profile path inside that directory, and check every write against it.
- Write every documentation file (README, `docs/`, guides) with the `unslop` skill. Read `skill://unslop` before drafting, and run the finished text through it.
